# Shared research brief

Public, password-free HTML research brief for cofounder discussion.

- Site: https://f-lab-jd.github.io/shared-briefs/
- Source document: the local project's `report.html`; publish the sanitized HTML as `index.html`.
- Scope: AI trend-template venture, economics, cofounder roles, payment providers, country strategy, East Asia and Southeast Asia.
- Public-data review date: 2026-10-02. Provider approval and live payment/settlement are not verified.
- Publication convention: shared research reports are password-free unless the user explicitly requests protection. Do not publish personal identity, private employment context, credentials, local operational configuration, or private build scripts.
- `noindex` and `robots.txt` are search-engine requests, not access control. Anyone with the URL can read and redistribute this content.
- This repository and its hosting account are public. Do not claim anonymous hosting.
- Preserve existing reports when adding research. Keep policy facts, estimates, assumptions, and unverified onboarding conditions clearly separated.
